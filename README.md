# Crypto Monitor V3 Profesional

## Novedades
- Interfaz financiera oscura y navegación lateral.
- Dashboard, Oportunidades, Radar, Evolución, Alertas, Portfolio, Backtesting y Configuración.
- Configuración editable desde la web.
- Corrección del cálculo de Δ Score.
- Historial de scores.
- Señales y niveles operativos visibles en tarjetas.

## Ejecutar
```bash
pip install -r requirements.txt
streamlit run app.py
```

Para uso cotidiano, CMD solo mantiene Streamlit en ejecución. Los parámetros del scanner se modifican desde Configuración.
